Student Performance Analysis

About the Project

This project analyzes student academic performance using Python, Pandas, Matplotlib, and Streamlit.

It helps understand student marks, study habits, attendance, and other factors affecting academic performance.

Features

- Student performance analysis
- G1, G2, and G3 marks analysis
- Top 10 students
- Study time vs final marks
- Attendance and absence analysis
- Gender-wise performance
- Correlation analysis
- Interactive Streamlit dashboard

Technologies Used

- Python
- Pandas
- Matplotlib
- Streamlit

Dataset

The project uses the Student Performance Dataset ("student-mat.csv").

How to Run

1. Install the required libraries:
   
   "pip install -r dataset/requirements.txt"

2. Run the application:
   
   "streamlit run dataset/app.py"
